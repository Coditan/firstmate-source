# fm-transcript patterns - read by the tool, NEVER typed on a command line.
#
# Format:  <class><TAB><flags><TAB><regex>
#   flags: "whole"  -> redact the entire match
#          "g<N>"   -> redact only capture group N, keep the rest as context
#
# SELF-SAFETY RULE (this file's own text must not match its own patterns):
# every literal trigger substring is broken with a one-character class, e.g.
# "sk[-]ant[-]" matches the real prefix but the text "sk[-]ant[-]" does not
# match it back. That keeps this file, and any transcript that recorded its
# authoring, from registering as a hit forever after. sc1's trap #6, closed at
# the authoring step rather than only at the running step.

# ---------- prefix-anchored: a known vendor prefix introduces the value ----------

# ---------- context-anchored: the surrounding text names the value ----------
# group 1 is the value; everything around it survives so the archive still
# records THAT a credential was there, of what kind, in which session.
assigned-secret	g1	(?i)(?:pass(?:word|wd)|secret|api[_\-]?key|access[_\-]?key|client[_\-]?secret|auth[_\-]?token|[_\-]token|^token)["']?\s*[:=]\s*["']?([^\s"',;)}\]]{10,})
