# Issue tracker

Firstmate uses the fleet backlog as its issue tracker; GitHub carries pull requests only.
The queue path is `data/backlog.md`; use `tasks-axi` for backlog operations and see `AGENTS.md` section 10 for the backlog contract.
Use `/to-backlog` to size a plan, spec, or report into work items, and use `decision-hold-lifecycle` for captain decisions.
Use `gh-axi` for GitHub pull request operations.
`AGENTS.md` section 1 owns the rule that because firstmate never writes to a project, work for a project becomes a fleet backlog item rather than an issue filed in that project's repository.
