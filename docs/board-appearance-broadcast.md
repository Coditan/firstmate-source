# All-Ships notice: local board appearance

This notice travels with the code change that makes board appearance local.
It sets no deadline and asks for no reply.

> Each seat already created its own design language through its own work.
> It has gone unused because shared Firstmate code supplied one vessel's appearance after that work and every updated seat received it.
> That was a defect in the shared code, not a failure by any seat: nobody copied another vessel's design; it was shipped to everyone.
>
> Board structure is now shared and board appearance is local.
> When you choose to adopt your existing design, place its self-contained appearance fragment at `$FM_HOME/config/board-appearance.html`.
> Until then, boards use a visibly labelled neutral default and remain fully usable.
>
> Ours is named Tally, and it is ours only.
> Nothing about its palette, type, marks, or component styling is carried in this notice or in the shared board assets.
>
> Adopt your own design in your own time.

## Maintaining this file

Keep this as the exact notice that accompanies the local-appearance change.
Do not add another vessel's design details, a deadline, or a reply request.
